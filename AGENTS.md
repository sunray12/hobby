# Instructions for AI contributors

- Read [CONTRIBUTING.md](CONTRIBUTING.md) and [the engineering log](docs/engineering-log.md), then open the relevant build's README and review.
- Preserve `main` as a reviewed baseline. Use a topic branch from `develop`; never push, merge, change rules, or rewrite remote history without the owner's explicit approval.
- Log the exact CAD file hash, part library, tools, results, and unresolved issues. Keep static inspection, inventory reconciliation, contacts, and motion separate.
- Treat this repository as public. Do not commit credentials, private conversation history, account details, or files with unclear redistribution rights. Retain source credits and licenses.
